# Proveedores gratuitos: Fase 4

EduStudio admite Gemini, OpenRouter, Groq y una instancia Ollama administrada. Las listas `EDUSTUDIO_GEMINI_FREE_MODELS`, `EDUSTUDIO_OPENROUTER_FREE_MODELS`, `EDUSTUDIO_GROQ_FREE_MODELS` y `EDUSTUDIO_OLLAMA_FREE_MODELS` están vacías por defecto: ningún modelo funciona hasta que el administrador compruebe que ese identificador y esa operación son gratuitos para la cuenta y lo incluya. OpenRouter suele usar sufijos como `:free`, pero el sufijo por sí solo no basta para habilitarlo. Los planes y la disponibilidad cambian; hay que verificarlos periódicamente. Ninguna suscripción de chat concede crédito de API por sí misma.

Cada docente guarda su propia clave de Gemini, OpenRouter o Groq y confirma la gratuidad del modelo en su cuenta. La clave se cifra en el servidor, nunca se devuelve al navegador, y al sustituirla se borran las confirmaciones previas. Ollama es **solo para la fase de pruebas** (el servidor de desarrollo no tiene potencia para ofrecerlo como servicio) y se configura solo mediante `EDUSTUDIO_OLLAMA_BASE_URL` en el servidor, con acceso de red interno y modelos permitidos por el administrador; no utiliza clave personal. Una petición indica siempre proveedor y modelo. La alternancia autorizada y las reservas se detallan en [quotas.md](quotas.md).

Consolas oficiales para crear una clave personal: [Google AI Studio](https://aistudio.google.com/app/apikey), [OpenRouter](https://openrouter.ai/settings/keys), [GroqCloud](https://console.groq.com/keys), [OpenAI](https://platform.openai.com/api-keys) y [Anthropic](https://console.anthropic.com/settings/keys). [Ollama](https://ollama.com/download) requiere instalación y configuración del servidor. En producción debe usarse HTTPS. Evita enviar datos identificables del alumnado y revisa las condiciones de cada proveedor antes de usarlo con datos educativos.

La Fase 5 incorpora OpenAI, Anthropic y modelos de pago BYOK de proveedores habilitados por el administrador. Sus precios, aceptación y presupuestos se describen en [paid-models.md](paid-models.md). Los modelos de imagen tienen una selección y cuotas propias previstas para la Fase 6.
